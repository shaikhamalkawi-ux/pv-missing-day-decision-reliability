# Data and code availability

Public reproducibility repository: https://github.com/shaikhamalkawi-ux/pv-missing-day-decision-reliability

## Public data

### EURAC
Official public dataset: https://doi.org/10.5281/zenodo.18316996

The repository does not redistribute the EURAC raw archive. The R19 scripts accept a locally downloaded official archive and verify its expected checksum before analysis.

### MORE-EU
Official repository: https://github.com/MORE-EU/OpenData

The R20/R22 analysis pins `Solar Park Data -INACCESS/Array Power.csv` Git blob:

`5611277efdd581bb839ec380239846a43ebe0ba7`

The raw file is not redistributed here.

## Restricted data

PROPRE.MA donor raw files are restricted and are not included. Public materials expose only publication-level derived summaries and code. Raw-source replay requires authorized access.
